# wordpress.org SVN assets

These files are **not** part of the plugin zip. They belong in the `assets/`
directory at the **root** of the plugin's wordpress.org SVN checkout (sibling of
`trunk/` and `tags/`), where wordpress.org reads banners, icons, and screenshots.

| File | Purpose |
|------|---------|
| `screenshot-1.png` | Settings tab — maps to entry 1 in `readme.txt` `== Screenshots ==` |

To add more screenshots: drop `screenshot-2.png`, `screenshot-3.png`, … here and add
matching numbered lines under `== Screenshots ==` in `readme.txt`.

Recommended additional assets to drop here before submission:
- `icon-128x128.png` and `icon-256x256.png` (plugin icon)
- `banner-772x250.png` and `banner-1544x500.png` (plugin header banner)
